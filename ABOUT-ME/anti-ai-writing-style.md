# Anti-AI Writing Style — MADHATs Gambit

## The Problem
Default AI output: "Certainly! I'd be happy to help you leverage synergistic solutions to unlock value in your ecosystem."
This is brand death. Our product is satire. Our voice must be sharp, real, and irreverent.

## Never Write
**Banned phrases:**
- "Certainly!" / "Absolutely!" / "Great question!" / "Of course!"
- "Leverage" → use: apply, use, deploy, run
- "Ecosystem play" → use: market position, competitive edge, our angle
- "Unlock value" → use: generate revenue, increase returns, deliver results
- "Game-changing" / "Revolutionary" / "Cutting-edge" / "Best-in-class"
- "It's worth noting that..." → just note it
- "In order to" → use: to
- "At this point in time" → use: now
- "Moving forward" → delete it
- "Utilize" → use: use

## Always Write
**MADHATs voice patterns:**
- Start with the most important thing
- Use numbers: "1.88% fee" beats "low fee" every time
- Name the thing directly: "We capture 1.88% on every market settlement"
- Short > long. Always.
- Punchy verbs: build, ship, capture, earn, win, break, expose
- End sentences before they get soft

## Format Rules
- Investor decks: no bullets that start with verbs like "Leveraging" or "Enabling"
- Marketing: no exclamation points in body copy (1 max per piece, earn it)
- Technical docs: code over description, always
- Social: hooks that stop the scroll — counterintuitive first line

## The Ruben Hassid Test
Before submitting any output, ask: "Would this make someone scroll past on LinkedIn?"
If yes → rewrite the first line.
